# What is Samy?

**Samy** is a Discord bot that tries to put most of the things you'd normally need multiple bots for into one.

Moderation, utility commands, server tools, integrations, and more are all part of the same bot. The idea isn't to make Samy do absolutely everything, but to give servers a solid set of tools without needing a bot for every individual feature.

<Callout type="warning" title="Still in development">
  Samy is still being built. Some commands are unfinished, things may change,
  and bugs are expected. The documentation will also change as new features are
  added.
</Callout>

---

## Where is Samy right now?

We're currently working on the core systems that Samy is built on, along with new commands and features.

If you want to keep up with development:

- Join the **[Discord Server](/discord)** to talk with us and report bugs.
- Check the **[Status Page](/status)** for uptime and shard information.
- See what's currently available on the **[Commands Page](/commands)**.

## What can I expect?

Samy is going to change quite a bit while it's being developed. Commands might be added, removed, or changed, and some parts of the bot may not be finished yet.

If something doesn't work as expected, let us know. It helps us figure out what needs fixing.
